# Rock Paper Scissors Game

A classic, interactive browser-based Rock Paper Scissors game built with HTML, CSS, and vanilla JavaScript.

## Features
* **Interactive UI:** Clickable choice elements feature smooth scale and background color transition effects on hover.
* **Game Logic:** The computer randomly selects its move, and the winner is evaluated dynamically.
* **Real-Time Score Tracking:** The application keeps a running tally of both the user's and the computer's score during the session.
* **Dynamic Feedback:** The message board updates its text and background color to reflect the round's outcome—green for a win, red for a loss, and dark blue for a draw.

## Technologies Used
* **HTML5:** Structures the game board, choice containers, and scoreboard.
* **CSS3:** Provides flexbox layout styling, custom colors, and interactive transition effects.
* **JavaScript:** Powers the core mechanics, event listeners, and DOM manipulation.

## File Structure
* `index.html`: The main web page containing the game's layout.
* `style.css`: The stylesheet handling the visual design and layout.
* `app.js`: Contains the logic for generating computer choices, comparing moves, and updating the UI.
* `/image/`: Directory containing the game icons (`rock.png`, `paper.png`, `scissors.png`).

## How to Run
1. Clone or download the repository files to your local machine.
2. Ensure the three image files (`rock.png`, `paper.png`, `scissors.png`) are placed inside a folder named `image` within the same directory as the HTML file.
3. Open `index.html` in any modern web browser to start playing.
